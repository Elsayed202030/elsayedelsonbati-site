خطوات الإطلاق الفعلي للموقع

كيف تنشر ELSAYEDELSONBATI على GitHub و Netlify / Vercel مع دومين مخصص؟

خطوات عملية مباشرة لنقل موقعك من ملفات محلية إلى موقع حيّ على الإنترنت برابطك الخاص.

01

تجهيز ملفات المشروع

ضع ملف index.html وملف الشعار elsayedelsonbati-logo.svg داخل مجلد واحد مرتب وتأكد من عمل الصفحة محلياً في المتصفح.

02

رفع المشروع إلى GitHub

أنشئ مستودعاً جديداً (Repository) على GitHub باسم مثل elsayedelsonbati-portal وارفع الملفات إليه لتتبع التعديلات بسهولة.

03

الربط مع Netlify أو Vercel

سجّل في Netlify أو Vercel، اختر Add new project واربط مستودع GitHub ليتم النشر التلقائي مع شهادة أمان SSL مجانية.

04

ربط الدومين المخصص

احجز نطاقاً مثل elsayedelsonbati.com ثم أضفه في إعدادات النطاقات وأحدّث سجلات DNS (A / CNAME) لدى مزوّد النطاق.
